Workstation Tool Suite

Direct Single-Key Toolset

11 dedicated primary painting tools and 2 modifier subsystems accessible via established 3D DCC muscle memory shortcuts.

Brush Tool

B / 1

Direct 3D freehand material painter. Writes BaseColor, Roughness, Metalness, and Normal relief directly into texture maps.

  • Interactive resize with [ / ] or Right-Click Drag
  • Stylus pressure mapped to radius and opacity
  • Angle, size, and color jitter options

PBR Eraser

E / 2

Non-destructive coverage removal. Subtracts layer alpha to reveal underlying layers without corrupting PBR channels.

  • Full support for textured .abr brush tips
  • Independent opacity and hardness sliders
  • Erases grayscale masks to unmask paint

Texture Stamp

T / 3

Single-dab decal projection tool. Places cropped textures or alphas onto 3D surfaces with rotation and scale control.

  • Rotate decal with R / Shift+R (±15°)
  • Clamp decal bounds to eliminate edge repeat
  • Generates tangent normal displacement from alpha

Fill Bucket

G / 4

Point-and-click flood fill. Fills solid colors, cropped textures, or full PBR material sets across pieces, faces, or clicked triangles.

  • Click and drag to sweep-fill consecutive triangles
  • Fit or repeat-tile placement modes
  • Respects active polygon face selection masks

Line Tool

L

Straight surface-interpolated lines. The line walks screen space and raycasts back onto the mesh, preventing strokes from tunneling.

  • Hold Shift to snap line angles to 45° increments
  • Renders all 4 PBR channels along trajectory
  • Cleanly terminates at surface silhouettes

Gradient Ramp

D

Drag across the 3D model to paint linear or radial color ramps with multiple color stops and opacity blending.

  • Unlimited color stops with live ramp preview
  • Linear directional and circular radial modes
  • Shift-snapping for 45° planar alignment

Effects Brush

U / 7

Surface filter brush that reworks existing paint across four modes: Directional Smudge, Gaussian Blur, Sharpen, and Pixelate.

  • Smudges along stroke motion vectors
  • Filters color and PBR channels together
  • Pixelate mode creates retro PSX texel grids

Eyedropper

I / 5

3D surface sampler. Samples color and material parameters directly from the viewport, including from non-active mesh pieces.

  • Hold Alt on any active tool for fast sampling
  • Cross-piece sampling without switching pieces
  • Add sampled colors directly to project palette

Face Selection

V / 6

Surface masking engine. Restricts painting, stamping, and filling strictly to selected triangles.

  • Alt+Click selects entire connected UV island
  • Save named selection groups into project file
  • Hold Ctrl+Drag to select on any tool

Face UV Projector

P / 8

TrenchBroom-style face texturing. Select faces, choose a texture region, and adjust placement with a live lit 3D preview.

  • Fit-to-selection mode for trim sheets
  • Repeat tile mode with scale factors
  • 90° snap rotation and precision offsets

Text on Faces

Y

Direct typography decal tool. Type text, choose installed system fonts, customize fill and stroke, and bake onto faces.

  • Live font picker for all installed system fonts
  • Independent fill color, stroke width, and outline
  • Positioned via Face UV Projector geometry

Screen Stencil

S

Floating camera-plane stencil overlay. Paint through reference images onto your model or stamp decals in one click.

  • Model orbits freely beneath locked stencil
  • Paste crops directly with Ctrl+V
  • Brightness masking or direct color stamping

Game Engine Integration

Direct Export to Major Engines

No manual channel recombining in external image editors. MeshCoat packages your painted channels into engine-standard texture maps on export.

ORM Packed 3-Channel Texture
RED Channel Ambient Occlusion (AO) from cavity generators or imported passes.
GREEN Channel Roughness map · Linear color space (0.0 gloss → 1.0 matte).
BLUE Channel Metalness mask · Linear color space (0.0 dielectric → 1.0 metal).

Unreal Engine 5

PBR / Nanite
Plug MeshCoat's packed _ORM.png directly into your material graph: R → Ambient Occlusion, G → Roughness, B → Metallic. Set Texture Group to Masks (no sRGB).
Color: _BaseColor.png ORM: _ORM.png (RGB) Normal: _Normal.png (DirectX/Tangent)

Unity (URP / HDRP)

Lit Shader
Compatible with Unity's Mask Map format. Use MeshCoat's export presets to write individual unpacked maps or packed ORM channels matching URP Universal Lit.
Albedo: _BaseColor.png Mask Map: _ORM.png Normal: _Normal.png

Godot 4.x

StandardMaterial3D
Turn on Roughness > Texture Channel = Green and Metallic > Texture Channel = Blue in Godot's StandardMaterial3D inspector to use MeshCoat's ORM map without modifications.

Source Repository

Build Directly From Source

MeshCoat is built with TypeScript, Electron, Three.js, SolidJS, and Bun.

bash — terminal
# Clone the repository
$ git clone https://github.com/stuyk/meshcoat.git
$ cd meshcoat

# Install dependencies with Bun
$ bun install

# Run in local development workstation mode
$ bun run dev

# Or package standalone binaries for your OS
$ bun run build:linux # AppImage, deb, tar.gz
$ bun run build:win # NSIS installer, portable .exe
$ bun run build:mac # DMG, zip
